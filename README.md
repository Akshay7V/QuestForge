
# QuestForge

A modular, turn-based RPG battle engine built incrementally to demonstrate core Object-Oriented Programming (OOP) principles and software design patterns.

## Overview

QuestForge is structured as a progressive, milestone-driven project. Each stage introduces a new architectural concept or design pattern that integrates directly into the existing codebase without discarding previous work. Upon completion, all modules combine into a playable turn-based combat engine showcasing over 15 OOP concepts and design patterns.

## Implementation & Language Support

- **Primary Implementation:** Python
- **Language-Agnostic Design:** Core concepts and milestones are specified using plain-English requirements and pseudocode, allowing the system to be implemented in Python, Java, C#, C++, JavaScript, Go, or any other object-oriented language.

## Getting Started

### Prerequisites
- Python 3.x (or an equivalent runtime for your chosen language)
- Git

### Installation
```bash
git clone https://github.com
cd QuestForge
```

### Usage
```bash
python main.py
```
